Mijn blog, gehost op GitHub Pages en live op blog.errornoslash.be. Hier documenteer ik de projecten die ik maak.

                        
Gebouwd met Zola: één binary, geen runtime, output is gewoon statische HTML. Het Terminus-thema zit als git submodule in de repo, met daarbovenop een eigen kleurenschema in CSS-variabelen. Posts zijn Markdown-bestanden met wat front matter, en een push naar main bouwt en deployt de site.
